# The Session Book — V7

V7 builds on V6 with a responsive, editable Session Planner optimised for computer, tablet and phone.

## V7 changes
- Drag-and-drop session ordering on desktop/tablet.
- Touch-friendly stacked editor on phones.
- Replace individual drills without rebuilding the whole plan.
- Remove blocks and add new blocks.
- Rebalances available minutes after editing.
- Save/load uses browser localStorage under a V7 key.
- Print layout remains clean and touchline-friendly.
- Preserves V5/V6 features including Back to top and the 50-drill library.

## Responsive targets
- Desktop: full-width planner with compact multi-column controls and editable timeline.
- Tablet: two-column controls and comfortable touch targets.
- Phone: single-column controls, stacked cards, full-width actions and no horizontal scrolling.
