# The Session Book V5

V5 adds a consistent **Back to top** control to every HTML page, including the homepage, About page, 404 page and all 50 drill pages.

### Back-to-top behaviour
- Appears after the visitor scrolls down 420px.
- Smooth-scrolls to the top of the page.
- Respects `prefers-reduced-motion` for accessibility.
- Works by keyboard and has a visible focus state.
- Sits above page content without affecting the document layout.
- Hidden when printing.
- On small screens the control becomes a compact circular-style arrow button.

All V4 content, styling, diagrams and functionality are retained.
