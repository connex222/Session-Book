# The Session Book — Version 3

Version 3 keeps the V2 navigation and session-finder improvements and brings the 50 drill pages closer to a consistent coaching standard.

## What changed
- Added a short **Session rhythm** to every drill page.
- Standardised **Common mistakes** across the library where they were missing.
- Standardised **What good looks like** where it was missing.
- Added **Coach's language** to every session: short, usable touchline prompts.
- Added **Age groups and numbers** guidance where missing.
- Preserved the stronger existing bespoke coaching sections rather than overwriting them.
- Marked pages as `data-session-book-version="3"`.
- Added small print/CSS refinements for the new coaching blocks.

The content is intentionally concise: the aim is to help a coach deliver the practice, not bury the session under theory.
