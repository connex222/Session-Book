# The Session Book — V4

V4 is the coach-first drill-page redesign.

## What changed
- Drill pages now use a two-column coach dashboard layout.
- The pitch diagram is the visual anchor.
- Session-at-a-glance sits in a dedicated sidebar.
- Objective, setup and key coaching points are easier to scan.
- Common mistakes, what good looks like and coach language are grouped as practical coaching cards.
- Progressions and age/number adaptations are surfaced clearly.
- Session rhythm, private notes, save, print and share remain available.
- Added diagram full-screen mode where supported by the browser.
- Existing 50-session library, SVG diagrams, SEO metadata and GitHub Pages architecture are retained.

V4 deliberately keeps the site static and dependency-light.
