# The Session Book — V2

This version keeps the original static GitHub Pages architecture and adds:

- practical session finder by squad size, duration, theme and level
- local browser saved sessions (no account required)
- private coach notes stored only in the browser
- session-at-a-glance cards on every drill page
- improved touchline/print workflow
- consistent metadata presentation without changing the original coaching content

The site remains static: HTML, CSS and JavaScript only.
